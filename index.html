Installer

  • Application Windows : lance l'installateur. À la première installation, Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même. Les mises à jour suivantes s'installent ensuite toutes seules, hors séance, vérifiées par la signature de l'auteur ; suivi, bilans, évaluations et dossier de sauvegarde sont gardés.
  • Passer du navigateur à l'application : dans le navigateur, Réglages › Sauvegarde › Sauvegarder tout ; dans l'application, Charger une sauvegarde.
  • Navigateur (autre ordinateur) : la page Vocabulaire.html s'ouvre dans Edge, Chrome ou Brave, sans installation.
